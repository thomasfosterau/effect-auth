# Architecture Decision Records

These ADRs are historical decision records that predate the July 2026 API
restructure, so they use pre-restructure names and paths (e.g. `TwoFactor`,
`HttpServer.ts`, flat `src/<Feature>.ts` modules). They are deliberately left
as written. See [docs/migration.md](../migration.md) for the full old → new
rename and move table.
