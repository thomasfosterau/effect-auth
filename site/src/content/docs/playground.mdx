The examples below boot a Node.js runtime inside your browser using
[StackBlitz WebContainers](https://webcontainers.io/) and execute real Effect
programs. The first run installs dependencies; subsequent runs reuse the
container.

:::note
WebContainers require a Chromium-based browser and a cross-origin-isolated
page. This site sets the necessary `COOP`/`COEP` headers in dev and via
`public/_headers` in production.
:::
