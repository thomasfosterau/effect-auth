## Why Effect Auth

<CardGrid stagger>
  <Card title="Effect-native" icon="puzzle">
    Built around `Request`/`Resolver`, services, and layers — no framework lock-in, no global state.
  </Card>
  <Card title="Batteries included" icon="rocket">
    Sessions, password hashing, OTP, WebAuthn, OAuth, magic links, two-factor, organizations, admin,
    API keys, JWT, enterprise SSO, and a full OIDC provider — plus a mountable HTTP handler with
    typed clients.
  </Card>
  <Card title="Drop-in primitives" icon="setting">
    Use just the pieces you need. Bring your own storage, transport, and identity model.
  </Card>
  <Card title="Try it live" icon="seti:typescript">
    Real, runnable Effect programs in the browser — see [the playground](/playground/).
  </Card>
