---
title: Admin
description: User administration — listing, roles, bans, session revocation, and impersonation.
---

The admin module gives operators user management: paginated listing, role
assignment, temporary or permanent bans, session revocation, and
impersonation. An actor is an admin when `user.attributes.role` is
`"admin"` (or listed in the configured `adminRoles` / `adminUserIds`).

## Enable

```ts
import { Layer } from "effect";
import * as Auth from "effect-auth";

declare const adminUserStore: Auth.AdminUserStoreShape;

const admin = Layer.mergeAll(
  Auth.AdminService.layer({
    // adminRoles: ["admin"], adminUserIds: [], impersonationSessionDuration...
  }),
  Layer.succeed(Auth.AdminUserStore)(adminUserStore),
);
```

## Endpoints

All session-authenticated; non-admin actors answer `403`.

| Endpoint                            | Purpose                                              |
| ----------------------------------- | ---------------------------------------------------- |
| `POST /admin/users/list`            | Paginated listing (`limit`, `offset`, `searchEmail`) |
| `POST /admin/users/set-role`        | Set `attributes.role`                                |
| `POST /admin/users/ban`             | Ban (optional `reason`, `expiresIn`)                 |
| `POST /admin/users/unban`           | Lift a ban                                           |
| `POST /admin/users/remove`          | Delete a user                                        |
| `POST /admin/users/revoke-sessions` | Sign the user out everywhere                         |
| `POST /admin/impersonate`           | Issue a session AS the target user                   |
| `POST /admin/stop-impersonating`    | End the impersonation session                        |

## Impersonation

`impersonateUser` issues a short-lived session for the target user with
`attributes.impersonatedBy` set to the admin's id, so audit trails can
distinguish real activity from support access. Banned users fail session
validation until the ban expires or is lifted.

```ts
import { Effect } from "effect";
import * as Auth from "effect-auth";

declare const service: Auth.AdminServiceShape;
declare const admin: Auth.User;

const support = Effect.gen(function* () {
  const session = yield* service.impersonateUser(admin, "user-42");
  return session; // session.attributes.impersonatedBy === admin.id
});
```
