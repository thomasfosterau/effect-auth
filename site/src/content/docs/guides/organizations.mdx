---
title: Organizations
description: Multi-tenant organizations with members, invitations, and role-based permissions.
---

The organization module adds multi-tenancy: users create organizations,
invite members by email, and manage roles (`owner` / `admin` / `member` by
default). Authorization is enforced inside the service — every mutating
operation checks the actor's role.

## Enable

```ts
import { Layer } from "effect";
import * as Auth from "effect-auth";

declare const organizationStore: Auth.OrganizationStoreShape;

const organizations = Layer.mergeAll(
  Auth.OrganizationService.layer({
    // membershipLimit, invitationExpiresIn, creatorRole, ... all optional
  }),
  Layer.succeed(Auth.OrganizationStore)(organizationStore),
);
```

## Endpoints

All session-authenticated; `403` when the actor's role lacks permission.

| Endpoint                                              | Purpose                                      |
| ----------------------------------------------------- | -------------------------------------------- |
| `POST /organization/create`                           | Create (actor becomes owner)                 |
| `GET /organizations`                                  | List the actor's organizations               |
| `GET /organization/:id`                               | Organization + members                       |
| `PATCH /organization/:id`, `DELETE /organization/:id` | Update / delete                              |
| `POST /organization/set-active`                       | Record `activeOrganizationId` on the session |
| `POST /organization/:id/invitations`                  | Invite by email                              |
| `GET /organization/:id/invitations`                   | List invitations                             |
| `POST /invitations/:id/accept` / `reject` / `cancel`  | Resolve an invitation                        |
| `POST /organization/:id/members`                      | Add a member directly                        |
| `PATCH /organization/:id/members`                     | Change a member's role                       |
| `DELETE /organization/:id/members/:userId`            | Remove a member                              |

## The active organization

`POST /organization/set-active` stores the choice in
`session.attributes.activeOrganizationId` via
`SessionManager.setSessionAttributes`, so subsequent requests can scope
queries to the session's active tenant without another lookup.

## Service API

```ts
import { Effect } from "effect";
import * as Auth from "effect-auth";

declare const service: Auth.OrganizationServiceShape;

const program = Effect.gen(function* () {
  const org = yield* service.createOrganization("user-1", {
    name: "Acme",
    slug: "acme",
  });
  const invitation = yield* service.inviteMember("user-1", org.id, {
    email: "teammate@acme.test",
    role: "member",
  });
  return invitation;
});
```
